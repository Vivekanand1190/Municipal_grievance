Accessibility Statement

FixMyCity is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

1. Standards Compliance

We strive to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 level AA. These guidelines explain how to make web content more accessible for people with a wide array of disabilities.

2. Key Features

  • Keyboard Navigation: All interactive elements can be accessed using a keyboard.
  • Screen Reader Compatibility: We use semantic HTML to ensure compatibility with modern screen readers.
  • High Contrast: Our interface utilizes a high-contrast color palette for better readability.
  • Responsive Design: The platform is fully functional across devices of all sizes.

3. Feedback

We welcome your feedback on the accessibility of FixMyCity. Please let us know if you encounter accessibility barriers:

  • Email: access@fixmycity.gov.in
  • Phone: +91 80 1234 5678

4. Assessment Approach

FixMyCity self-assessed its accessibility through internal testing and automated accessibility auditing tools.
